# Backend Service Documentation

## Overview

The `backend` directory provides an Express service written in TypeScript. It serves static client files as well as API routes (health checks, Kanban persistence, and AI chat integrations).

## Architecture

- `src/server.ts`: Express application setup, static asset routing to `public/`, SPA fallback routing, and server lifecycle.
- `src/server.test.ts`: Vitest / Supertest tests for API health checking and static file delivery.
- `public/`: Static file directory (serves demo hello-world HTML or Next.js static export).
- `dist/`: Compiled JavaScript output generated by TypeScript (`tsc`).

## Scripts

- `npm run dev`: Run server in development mode using `tsx watch src/server.ts`.
- `npm run build`: Compile TypeScript code to `dist/`.
- `npm start`: Run production compiled server `node dist/server.js`.
- `npm test`: Run automated Vitest test suite.
